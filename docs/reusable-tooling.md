## Reusable Tooling (Pinned Choices)

- `culori` ^4 (LAB conversion + Delta-E, pure JS, RN-safe; NOT chroma-js)
- `expo-image-picker` ^15 (works in Expo Go without prebuild; NOT react-native-image-picker). Used for both pet photo upload (fur-match flow) and parent-side message attachments (photos and videos). For in-app video recording: pass `videoMaxDuration: 60` AND `videoQuality: '720p'` (yields ~5-15 MB H.264 for 60s of clinical video; eliminates need for an on-device compression library, no prebuild required). For gallery-picked videos: run post-pick checks on both duration (>60s rejected) and file size (>50 MB rejected with "please record a new video" message). Cap and quality locked 2026-05-08; server-side compression deferred to v1+ per `docs/risk-register.md` item 9.
- `expo-video` (parent app video playback). Modern Expo video player (replaces deprecated `expo-av` for video). Used inside `<InlineVideoOverlay />` to play parent-uploaded clinical videos in the inbox thread. Native iOS/Android player. No third-party library (no `react-native-video`, no `expo-av` for video). Dashboard uses native HTML5 `<video controls>` instead; both wrap in the same Paper-card overlay shell. (Locked 2026-05-08.)
- `expo-image-manipulator` (centre-crop + downscale to 64×64 thumbnail before clustering; 50× faster, indistinguishable result)

Reanimated 4 requires New Architecture (already on for SDK 54). Babel plugin is auto-applied by `babel-preset-expo`; do NOT add `react-native-reanimated/plugin` manually (it duplicates).

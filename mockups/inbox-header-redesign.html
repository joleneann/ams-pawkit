Mockup · Inbox header redesign · v2 · 2026-05-18

CTA-dominant header, redundant count removed

Two locks for v2: (1) the "51 parents are waiting on you" copy is gone — the rail's Inbox tab already carries that count, so repeating it in the header was triple-redundancy (rail badge + bar copy + in-tab badge). (2) "Start reply queue" outweighs the Awaiting/Replied tabs visually — the CTA is the action; the tabs are chrome. Below: 4 reference patterns from products that solve "primary action + filter chrome" well, then 4 reformulated mockup directions. Recommendation at the bottom.

Reference research

Four category-leading apps that visibly weight a primary CTA over secondary filter/nav chrome. Pattern through all four: the action is taller, more saturated, more shadowed; the filters read as ambient toggles.

Gmail · Compose
Compose is a saturated rectangle, ~48px tall, drop shadow, leftmost slot. Filter chips ("Primary / Promotions / Social") sit below as ~28px-tall ambient toggles. ~2x the button's optical weight vs. the filters.
Linear · Inbox
Filter pills inline, small, ghost-style. The "action" is implicit — clicking the first item IS the queue. No big button. But where Linear DOES surface a button (Create issue), it's the loudest element on screen by far.
Notion · Database header
New button is 36px tall, filled accent. Filter / sort / view dropdowns are 28px, muted, no fill — they're chrome. The size delta is small but the color delta is large.
Slack · DM list
New message sits top-left as a pen icon button on a circular fill. Filter pills (Unread / Mentions) below it are ghost outlines, ~24px tall, mute text colour. Strong visual contrast even though both sit in chrome.

Pattern lock: CTA = filled accent, 40-44px tall, shadow, larger text. Filter tabs = ambient, 24-28px tall, no fill in the resting state, smaller text. The eye reads CTA → list → filters (in that order), which matches the demo-day mental model: "I have replies to send; now let me decide which slice I'm looking at."

Option C — Minimal + live-pulse on the CTA

Cleanest action-dominant layout, with one small piece of header-level urgency preserved. The pulsing dot inside the CTA tells the vet "there's live work here" without restating the count that's already in the rail badge. CTA dominates the tabs by 20px in height + saturated fill + shadow. Filter tabs are demoted to ambient chrome. No empty whitespace, no stacked surfaces, no redundancy.

Fallback: Option B if the pulse feels too "marketing" / too animated for a clinical product. Same layout minus the pulse. Slightly quieter; perfectly legible.

Skip D for now — page titles can wait until you do the dashboard chrome audit. Skip E — breaks parity with the broadcasts list (which uses the same pill-pair tabs) and lowers tab discoverability.

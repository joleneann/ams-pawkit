Strand A · Design references · UI taste
Four cross-industry editorial / clinical-notes benchmarks
NEJM
Steal: 1928 issue contents page, serif masthead over a quiet sectioned table of articles. Sets the editorial-authority register for clinical body copy. Substitute for the live NEJM site (paywalled, 403s on scrape).
Notion
Steal: editorial document with bold H1 over quiet H2, generous left-rail breathing, no app chrome competing with body text. Document-as-the-product.
Linear
Steal: Linear issue peek card, ID + title + tight row of typed metadata chips (status, priority, cycle) above body copy. Metadata-then-prose rhythm maps onto visit-header-then-SOAP-body.
Athena Health
Steal: human-EHR ambient note with stacked labeled sections (Reason for visit, HPI, ROS) where each label sits above a dense paragraph block. Section-as-landmark scanning pattern in clinical setting.
Strand B · Category competitors · vet / healthcare clinical-notes UI
Four vet PMS + AI scribe benchmarks
ezyVet
Steal: vet PMS clinical record with collapsible Presenting problem / Master problems / Health status / Subjective sections stacked vertically, each with vet+date byline. Closest to expanded-newest, collapsed-older visit card model.
Provet Cloud
Steal: consultation-list with client + patient + start-time + reason + doctor columns in a tight row rhythm. Visit-list header anatomy specifically. (Provet hides actual SOAP composer publicly.)
Digitail
Steal: vet PMS clinical record with explicit S / O / A / P tabs across the top header + right-rail summary. Direct evidence of S/O/A/P navigational landmark pattern in a vet-specific UI.
Scribenote
Steal: vet AI scribe output with explicit color-coded S/O/A/P cards stacked vertically, each header above its own body. Closest visual analog to Pawkit's planned per-visit SOAP rendering.

Direction A
NEJM / case-report-channeled · editorial document
Single-column ~640px editorial flow. Document opens with a quiet title block, then each visit is a section with date / reason / vet byline above, S/O/A/P labels rendered as small-caps eyebrows with body paragraphs below. Maximum clinical authority via discipline, no decorative cards, no card chrome. Reads like a case-report article (Inter not serif, since locked type system bans new fonts, but the editorial rhythm comes through).

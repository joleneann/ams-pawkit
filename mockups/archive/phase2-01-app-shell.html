Phase 2 · Screen 01 · App shell + nav
Four chrome directions for the dashboard shell
Reference compilation (two strands) plus four HTML/CSS Pawkit directions applying each design reference. Pick one direction, or call out a mix.

Spec changes proposed in this round (need your nod before locking): header wordmark = AMS clinic name (Satoshi "Animal Medical Services" + Inter small caps "PUNE") instead of "Pawkit" wordmark; Teal brand dot dropped (had no defined job, the wordmark grounds itself); Direction D rebuilt with a compact visible search bar instead of a Mac-only ⌘K command-palette pattern (Sagar is on Windows and is not a keyboard-shortcut power user).

Constant across all four: three rail destinations (Inbox, Broadcasts, Settings) with Lucide icons (mail / megaphone / settings), Teal-left-border active state (never fill), context-aware search bar, no Pets tab, no In-Surgery toggle, desktop-only.
Strand A · Design references · UI taste
Four cross-industry chrome benchmarks
Linear
Steal: ultra-tight 13px sidebar type with monochrome icons and razor-thin padding; chrome disappears so list content reads as the page.
Stripe Dashboard
Steal: small-caps section labels above rail groups; vertical hierarchy through type discipline, not borders.
Notion
Steal: faint, almost-invisible section labels in muted grey caps; user content (pet names) becomes the visual hierarchy, not the chrome.
Superhuman
Steal: borderless near-flush rail, zero header density; lesson applied as ultra-compact chrome (visible search bar kept; Sagar is not the cmd-K power user Superhuman targets).

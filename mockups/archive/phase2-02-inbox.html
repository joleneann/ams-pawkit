Strand A · Design references · UI taste
Four cross-industry inbox / list benchmarks
Linear
Steal: row marries circle avatar to single-line title + muted meta-line + far-right time-since, with a tiny status dot doing all the read/unread work — clean anatomy for pet avatar + last-message preview + time.
Superhuman
Steal: tabs run as plain text labels with small count badges, active tab is just brightened (no pill, no underline tweenery); adapt for Pawkit's Active/Inactive subtabs + awaiting-reply count.
Hey by Basecamp
Steal: sender name bolder than preview, date column grey + right-flush; the only unread cue is a single dot left of avatar — minimal unread signal that maps directly to Pawkit's pet-name/preview stack.
Things 3
Steal: generous vertical padding + almost-invisible hairline divider; quiet left gutter for avatars (where Things uses checkboxes); 20 rows feel calm, not packed.
Strand B · Category competitors · feature grounding
Three vet / healthcare practice mgmt inboxes
Klara
Note: mixed-unit relative time strings ("Jan 1", "1 day", "18 hours", "1 hour", "30 minutes") — more human than absolute dates and exactly right for Pawkit's time-since requirement.
Petdesk
no public screenshot
Petdesk
Note: uses Active / Archived subtab split (closest analogue to Pawkit's Active / Inactive). Inbox screenshots gated behind login; lesson from docs only, not screenshot.
Weave
Note: small colored tag-chips ("Billing", "Outstanding", "Review") sit beneath the preview line — a way to surface follow-up state ("Post-Op Day 3", "Med refill") without adding a column. NOT in Pawkit v0 scope; flagged for future.

Strand A · Design references · UI taste
Four cross-industry right-rail-with-thread benchmarks
Linear
Steal: right sidebar stacks metadata (Status, Priority, Assignee, Labels) as quiet rows of icon + value, never crowding the main detail column.
Healthie
Steal: chronic conditions + allergies as persistent header chips; clinician sees clinical context before clicking anything.
Notion
Steal: breadcrumb in a quiet top strip well above the page header; generous vertical breathing room.
Stripe Dashboard
Steal: high-value identifiers as a tight scannable block at the top of the right rail; secondary records flow below.
Strand B · Category competitors · feature grounding
Three vet / healthcare patient thread views
Petdesk
Note: co-locates pet identity + vaccine status + reminders in a single dense card — counter-example to the noise Pawkit's quieter layout strips out.
Klara
Note: patient thread foregrounds the open conversation banner above all metadata — direct precedent for the open-follow-up banner.
Weave
Note: patient panel groups recent activity as a chronological feed with typed event icons — validates Ink-soft event icons for the clinical history.
Reading the directions below. Same chrome on top, same conversation content (4 alternating bubbles), same 8 clinical history entries in the panel. What varies: chronic-chip style, Quick Facts grammar (rows vs. bordered card vs. stacked vs. filled-tint card), Clinical History row anatomy (compact vs. card vs. editorial vs. dense table).

E Empty state (locked spec)
The locked Empty state per layout-spec.md Screen 9 State A. Ink-faint cover with diagonal-stripe placeholder, dashed +avatar, hint card. The mockup represents the before-fur-match state explicitly. Demo runs the upload-to-fur-match flow live, so the cover evolves through Empty, Sampling, Transformed.

Pro: honest about the empty state. Sets up the live fur-match demo beat. No commitment to a specific stand-in photo.
Con: the brand-hero claim is only true post-photo-upload; the screenshot of Gabby's page in this state is a "before" photo, not the hero. Demos and screenshots both depend on showing the post-upload state, so this state is rarely screenshot-worthy.

What to compare when choosing

  • Brand hero claim: the locked decision is that the steady-state Pet Page is the brand hero AND the demo's emotional center. Which option carries that claim most honestly without depending on the photo being perfect?
  • Photo dependency: Options B and C live or die by the photo quality. Option A is more forgiving (circle crop). Options D and E sidestep the photo entirely.
  • Editorial vs intimate: B and C lean editorial (Aperture, Vogue). A leans intimate (Things 3, Substack). D leans typographic. E is honest-empty.
  • Demo screenshot: what does Sagar see in the screenshot Jolene sends after the demo? Each option produces a different screenshot story.
  • v0 implementability: all five are equally easy to build. Photo source is the only variable. A and B need a stand-in photo today. C needs the same plus a CSS filter. D needs zero photo. E is already specced.
  • What ages well: when the Fernandes shoot lands and the real Gabby photo replaces the placeholder, which option still feels right? D becomes redundant; A, B, C all improve. E disappears (Empty state ceases to be the steady state once Gabby has a photo).

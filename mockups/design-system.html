Pawkit v0 design system

Design tokens, primitives, and patterns for the AMS pitch demo

A single visual reference for the colors, type, and components used across the Pawkit dashboard and parent app. Everything below mirrors what actually ships in apps/dashboard. Locked tokens live in packages/design-tokens; consumed via Tailwind preset.

UI
Every primitive on this page is a shadcn primitive. Buttons, inputs, textareas, tabs, badges, avatars, dialogs, popovers, dropdown menus, sheets, tooltips, skeletons, checkboxes, toggle groups, all of them. There are no hand-rolled UI primitives anywhere in apps/dashboard. If a primitive is missing, the rule is: install the matching @radix-ui/react-* package and add a shadcn wrapper at components/ui/<name>.tsx BEFORE writing any <button> / <input> / <textarea> / <div> with classnames. Locked 2026-05-15 final after four audit rounds.

Surface architecture

Two surface tones only. Rail tint is the workspace ground (top bar, rail, content gutter). Canvas is what lifts off the ground (cards, modals, panels). No drop shadows: elevation comes from tonal contrast + a 1px rule hairline.

Ground · rail-tint #EFE6E8
Canvas card · #F8F7F5 + 1px rule hairline + 12-14px radius
Cards lift off the ground by hue and tone, not by shadow. This is the entire elevation system.

Buttons

Primitive: shadcn Button · components/ui/button.tsx

Pawkit <Button /> is the shadcn cva primitive driven by the --primary token. Five used variants × five sizes. cta is the Pawkit-specific size for the primary action on a screen (40px tall, 24px horizontal padding). The shadcn destructive variant is inherited but unused in Pawkit v0 (zero source references): its default red #B43B3B clashes with the mauve-only palette, and v0 has no destructive flows. Avatars

Primitives: shadcn Avatar (Radix) wrapped as PetAvatar · components/ui/{avatar,pet-avatar}.tsx

PetAvatar wraps the shadcn Avatar primitive: 3px fur-match ring carrying the pet's primary fur tone, 1.5px canvas bezel, inner photo. Three sizes: sm 36, md 46, lg 56. Fur tones are read from the seed; chrome NEVER uses fur tones.

Icons

Icon kit: Phosphor Icons · @phosphor-icons/react ^2.1.10 · weight=fill (global default)

Phosphor filled is the sole icon kit across the dashboard (locked 2026-05-15 evening). Lucide was ripped out the same evening. The global default weight: "fill" is set via components/chrome/icon-provider.tsx wrapping {children} in the root layout, so every @phosphor-icons/react import paints filled by default. Individual icons can override their own weight prop if a surface needs a lighter treatment. Sizes follow the 16 / 18 / 24 ladder. Mono-color via currentColor; never carry their own color outside this token system.

Discipline rules

Hard rules enforced on the build. Violations are reverted, not relitigated.

Locked 2026-05-15 final
NO hand-rolled UI primitives
Every interactive element in apps/dashboard must use a shadcn primitive from components/ui/. If a primitive is missing, install the matching @radix-ui/react-* package and add a shadcn wrapper BEFORE writing <button> / <input> / <textarea> with classnames.
Locked 2026-05-15 final
Type sizes from the Pawkit scale only
No text-[Npx] arbitrary values, no style={{ fontSize: N }} inline. Pull from text-xxs through text-display. Eyebrow letter-spacing is tracking-[0.14em] everywhere; never 0.12em or 0.16em.
Brand discipline
No em dashes anywhere
In docs, microcopy, UI strings, or code comments. Use commas, periods, colons, parentheses, or sentence breaks. Locked across project-wide voice.
Hardened 2026-05-08
Fur tones never in chrome
The 10 fur tokens are for pet fur matching only. The only allowed exception is Sable as the Sampling-state cover in fur-match, because the moment itself is about fur.
Surface architecture
No drop shadows
Elevation = tonal contrast + 1px rule hairline. Cards lift off the rail-tint ground by being canvas; rules separate sibling cards. Box-shadows are reserved for the focus ring only.
Colors
No pure white or pure black
All "white" in chrome is canvas #F8F7F5 or rail-tint #EFE6E8. All "black" is ink #0F0C0A. Pure #FFFFFF and #000000 are forbidden.
